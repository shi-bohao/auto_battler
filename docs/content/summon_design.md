# 召唤物设计

> 维护提示：召唤物分类、上限、生命周期和胜负判定等系统规则以 `docs/systems/summon_system.md` 为准。精确数值以 `docs/content_reference.md` 为准（下表数值为设计示例，当前以自动生成版本为权威）。本文档保留每个召唤物的设计定位和差异化用途。

## 召唤物总览

当前在 `data/summons/` 下有 8 个召唤物资源文件，外加 2 个敌方分裂单位也走召唤系统。系统层面的分类与来源见 `summon_system.md`。

### 正式召唤物

| 召唤物 | ID | 定位 | 设计要点 |
| --- | --- | --- | --- |
| 骷髅 / Skeleton | `summoned_skeleton` | 近战输出 | 脆弱但易于量产，被动「骨刃」对低生命目标增伤 20%。主动「骨斩」160% 攻击力 |
| 骷髅弓箭手 / Skeleton Archer | `summoned_skeleton_archer` | 远程物理 | 弹道攻击（arrow, 600速），低生命高输出。「骨箭」对低血目标增伤 20%。主动「穿骨箭」170% |
| 骷髅法师 / Skeleton Mage | `summoned_skeleton_mage` | 远程法术 | 弹道攻击（dark, 480速），极低生命。被动「残魂聚流」释放主动后回魔 10。主动「骨火爆裂」范围 AoE 140% 伤害 |
| 骷髅战士 / Skeleton Warrior | `summoned_skeleton_warrior` | 近战坦克 | 比普通骷髅更耐打。被动「骨盾守备」减伤 10%。主动「护骨斩」150% 攻击力 + 护盾 |
| 傀儡 / Puppet | `summoned_puppet` | 近战坦克 | 标记目标死亡后生成，生命较高。被动「傀儡身躯」减伤 10%。主动「傀儡护架」自盾 |
| 魂偶 / Soul Puppet | `summoned_soul_puppet` | 近战坦克 | 继承被标记目标 50% 生命与攻击，强度波动大。与傀儡共用被动和主动技能 |

| 骨龙 / Bone Dragon | `summoned_bone_dragon` | 远程范围 | 英雄专属（Lv.4+），攻击附带 30% 溅射。被动「龙息溅射」，主动「龙息弹幕」150% 范围伤害 |

## 属性来源

召唤物属性采用**固定基础值**模式：
- 属性写在 `.tres` 资源文件中作为默认值
- 生成时通过 `UnitDataApplier` 应用到运行时单位
- 骨巨人/骨龙的属性还会叠加织骨者英雄的攻击力比例加成
- 魂偶额外继承被标记目标 50% 生命与攻击，在基础属性之上叠加

## 召唤上限设计

- 默认 3；当前已实现的英雄强化「墓穴召唤」会通过 `summon_cap_bonus` 使玩家召唤单位上限 +1
- 骨巨人/骨龙为独立上限 1，不占用普通召唤上限
- 敌方分裂体使用独立的上下文上限（蛆虫 4、史莱姆 2）
- 遗物召唤（如骸骨坠饰）有独立的源上限
