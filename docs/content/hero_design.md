# 英雄系统设计文档

> 维护提示：英雄基础规则（选择/上场/升级/强化）以 `docs/systems/hero_system.md` 为准。当前已实现英雄的精确数值以 `docs/content_reference.md` 和 `data/heroes/*.tres` 资源文件为准。下方属性与技能数值为设计基线/构筑表达示例，后续调数后以自动生成的 `content_reference.md` 为唯一权威来源。本文档保留英雄设计意图、构筑方向、强化选项和后续扩展思路。

## 1. 英雄系统定位

英雄不是普通商店单位，而是玩家开局选择的核心单位，决定本局构筑方向，并通过多轮战斗逐步成长。

普通单位通过商店购买、备战席调整、升星合成、遗物联动形成阵容强度。英雄则提供更明确的构筑方向：

| 英雄 | 构筑方向 | 推荐阵容 |
|---|---|---|
| 铁誓统帅 | 防御、护盾、前排、持久战 | 战士、坦克、巨剑骑士、神官、牧师 |
| 奥术导师 | 技能、魔力、法术爆发 | 法师、炼金术士、爆弹投手、游吟诗人、风语者 |
| 血影猎手 | 暴击、刺杀、收割 | 刺客、弓手、巨剑骑士、爆弹投手 |
| 织骨者 | 召唤、亡灵、数量压制 | 亡灵法师、傀儡术士、缚魂祭司、骨巨人、骨龙 |

## 2. 英雄升级与强化设计

英雄通过经验值升级（50 经验/级，普通关 +10、精英关 +20、Boss 关 +30）。每次升级弹出专属强化三选一；已选强化不会重复出现；不足 3 个专属强化时用基础属性强化补齐。

### 强化类型

| 类型 | 设计意图 | 示例 |
| --- | --- | --- |
| 属性强化 | 直接提升英雄自身数值 | max_hp +15%、attack_damage +20%、defense +20、mana_regen +20% |
| 被动强化 | 强化英雄被动效果 | 铁誓军势防御加成提高、法术共鸣技能伤害加成提高 |
| 主动技能强化 | 提升主动技能数值或范围 | 统帅号令护盾提高、奥术风暴范围变大 |
| 阵容联动强化 | 引导围绕特定单位或职业构筑 | 每有 1 个承伤单位全队防御 +3 |
| 机制改变强化 | 新增规则级效果 | 护盾触发时恢复魔力、击杀后追加攻击 |

## 3. 英雄一：铁誓统帅 / Iron Oath Commander

### 定位

核心承伤与团队防御英雄。适合围绕前排坦克和治疗单位构筑。

核心关键词：**防御 / 护盾 / 前排 / 持久战 / 低血保护**

### 基础属性

```
max_hp = 320, attack_damage = 18, defense = 35
attack_interval = 1.2, attack_range = 60, move_speed = 70
max_mana = 120, mana_regen = 10.0, target_mode = NEAREST
```

### 被动技能 1：铁誓军势 / Iron Oath Legion

战斗开始时，所有玩家前排单位获得 `15 + 0.1*defense` 防御。承伤类单位（warrior/tank/greatsword_knight 等）额外获得 `20 + defense + 0.1*max_hp` 护盾。

**设计目的**：让铁誓统帅天然适合前排防守阵容。

### 被动技能 2：不倒战线 / Unbroken Line

任意玩家前排单位首次低于 40% 生命时，为其添加等同于已损失生命值的护盾。每单位每场战斗仅触发一次。

**设计目的**：提升前排单位的续航和容错。

### 主动技能：统帅号令 / Commanding Order

满魔自动释放。所有玩家单位获得 `25 + defense + 0.1*max_hp` 护盾，前排单位额外获得 `+20 + 0.1*defense` 防御，持续 5 秒。Lv.4 强化：护盾提升为 `40 + 1.5*defense + 0.2*max_hp`，防御提升为 `+35 + 0.2*defense`，持续 6 秒。

### 专属升级选项

| 升级名 | 效果 |
|---|---|
| 坚不可摧 | 英雄自身防御 +50 |
| 铁壁扩散 | 统帅号令的防御加成也影响中排单位 |
| 护卫协同 | 每有 1 个承伤单位，全队防御 +10 |
| 战线回响 | 玩家单位获得护盾时恢复 10 魔力，每单位每 2 秒最多一次 |
| 最终防线 | 英雄死亡时，所有玩家单位获得 100 + defense 护盾 |
| 重甲阵列 | 所有前排单位获得 max_hp * 0.2 |
| 护盾训练 | 玩家单位获得的护盾值提高 15% |
| 坚守号角 | 统帅号令额外治疗前排单位 10% 已损生命 |

### 推荐站位

前排中心，作为主坦或副主坦：(6,3), (6,2), (6,4), (5,3), (5,2), (5,4)

## 4. 英雄二：奥术导师 / Arcane Mentor

### 定位

技能流、魔力流、法术爆发英雄。适合围绕依赖主动技能的单位构筑。

核心关键词：**技能伤害 / 魔力回复 / 范围伤害 / 法术爆发 / 技能联动**

### 基础属性

```
max_hp = 180, attack_damage = 26, defense = 5, crit_chance = 5%
attack_interval = 1.35, attack_range = 140, move_speed = 85
max_mana = 100, mana_regen = 14.0, target_mode = NEAREST
```

### 被动技能 1：奥术回流 / Arcane Reflow

玩家单位释放主动技能时，奥术导师恢复 8 魔力。技能输出单位（mage/alchemist/bomb_thrower 等）释放时额外恢复 4 魔力。

**设计目的**：让技能流阵容形成连锁释放节奏。

### 被动技能 2：法术共鸣 / Spell Resonance

玩家单位造成主动技能伤害提高 10%。

**设计目的**：强化技能输出方向，形成明确的构筑成长曲线。

### 主动技能：奥术风暴 / Arcane Storm

满魔自动释放。以当前目标为中心，半径 120 内所有敌人受到 `attack_damage * 2.2` 技能伤害。Lv.4 强化：范围提升至 150，伤害提升至 `attack_damage * 2.8`，命中 3 个以上敌人时所有玩家单位恢复 15 魔力。

### 专属升级选项

| 升级名 | 效果 |
|---|---|
| 魔力涌动 | 所有玩家单位魔力回复速度 +10% |
| 法术穿透 | 玩家主动技能伤害无视目标 20% 防御 |
| 连锁施法 | 奥术导师释放主动技能后，随机友方单位恢复 30 魔力 |
| 炼金共振 | 场地持续伤害类技能伤害 +20% |
| 爆裂奥术 | 奥术风暴每额外命中 1 个敌人伤害提高 5%，最多 25% |
| 元素过载 | 法师、炼金术士、爆弹投手攻击力 +12% |
| 魔力护盾 | 玩家单位释放主动技能后获得 10 护盾 |
| 快速吟唱 | 奥术导师最大魔力 -15，但技能伤害降低 8% |

### 推荐站位

后排中间，作为技能流核心输出与魔力引擎：(1,3), (1,2), (1,4), (0,3), (0,2), (0,4), (2,3)

## 5. 英雄三：血影猎手 / Bloodshadow Hunter

### 定位

暴击、刺杀、收割英雄。适合围绕高暴击/高爆发单位构筑。

核心关键词：**暴击 / 收割 / 低血量目标 / 击杀收益 / 标记目标**

### 基础属性

```
max_hp = 220, attack_damage = 30, defense = 8, crit_chance = 15%, crit_damage = 1.8
attack_interval = 0.9, attack_range = 70, move_speed = 150
max_mana = 90, mana_regen = 12.0, target_mode = LOWEST_HP
```

### 被动技能 1：猎杀标记 / Hunt Mark

战斗开始时随机标记 1 个敌方后排单位，玩家单位攻击被标记目标时伤害提高 15%。

**设计目的**：制造"集火目标"和"后排威胁"玩法。

### 被动技能 2：血影收割 / Bloodshadow Harvest

玩家单位击杀敌人时，击杀者恢复 20 生命和 15 魔力。刺客或弓手击杀时额外获得 +10% 暴击率，持续 5 秒。

**设计目的**：强化击杀滚雪球和收割体系。

### 主动技能：血影突袭 / Bloodshadow Assault

满魔自动释放。对当前生命比例最低的敌人造成 `attack_damage * 2.6` 技能伤害；目标低于 50% 生命时伤害提高 30%；击杀目标后立即恢复 50 魔力。Lv.4 强化：伤害提升至 `attack_damage * 3.2`。

### 专属升级选项

| 升级名 | 效果 |
|---|---|
| 致命预感 | 全队暴击率 +8% |
| 猎手本能 | 刺客和弓手暴击伤害 +30% |
| 连续收割 | 玩家单位击杀后攻击间隔降低 15%，持续 5 秒 |
| 弱点暴露 | 被标记目标防御 -20 |
| 血影连斩 | 英雄主动技能击杀后可再次释放弱化版本 |
| 追猎节奏 | 被标记目标受到攻击时，攻击者恢复 5 魔力 |
| 残血猎杀 | 玩家单位攻击生命比例低于 35% 的敌人时伤害 +12% |
| 暗影庇护 | 刺客和弓手击杀后获得 25 护盾 |

### 推荐站位

中排侧翼，方便快速切入和收割：(4,1), (4,5), (3,1), (3,5), (4,2), (4,4), (3,3)

## 6. 英雄四：织骨者 / Boneweaver

### 定位

召唤、亡灵、数量压制英雄。适合围绕召唤物体系构筑。

核心关键词：**召唤 / 亡灵 / 数量压制 / 骨巨人 / 骨龙**

### 基础属性

```
max_hp = 160, attack_damage = 22, defense = 4, crit_chance = 5%
attack_interval = 1.5, attack_range = 130, move_speed = 80
max_mana = 120, mana_regen = 12.0, target_mode = NEAREST
```

### 被动技能 1：骨潮 / Bone Tide

战斗开始时所有玩家召唤单位获得 15% 攻击力和 15% 最大生命加成。场上每有 1 个玩家召唤单位，召唤单位伤害提高 5%，最多 25%。

**设计目的**：让召唤阵容的每一个单位都有更高威胁。

### 被动技能 2：不灭仆从 / Undying Servants

玩家召唤单位首次受到致命伤害时保留 1 点生命并获得 2 秒无敌，每单位每场战斗限 1 次。

**设计目的**：提升召唤物的生存窗口，防止被 AoE 瞬间清场。

### 主动技能：骨巨人召唤 / Bone Golem Summon

满魔自动释放。在最近敌人附近召唤一个骨巨人（近战肉盾），属性随英雄攻击力成长，持续 15 秒。Lv.4 起额外召唤一只骨龙（远程范围输出），攻击可造成溅射伤害。

### 专属升级选项

| 升级名 | 效果 |
|---|---|
| 骨骼强化 | 召唤物生命 +20% |
| 亡灵军势 | 场上每有 3 个召唤物，玩家全队伤害 +8% |
| 墓穴召唤 | 召唤上限 +1 |
| 骨刺外壳 | 召唤物受到近战攻击时，反弹 20% 伤害 |
| 亡语回荡 | 召唤物死亡时，周围友军恢复 15% 最大生命 |
| 死者行军 | 召唤物移速 +25%，攻速 +15% |
| 骨矛齐射 | 召唤物造成伤害时，有 20% 概率追加额外伤害 |
| 不灭军团 | 不灭仆从触发次数每单位每场战斗 +1 |

### 推荐站位

后排安全位置：(0,2), (0,3), (0,4), (1,2), (1,3), (1,4), (2,3)
