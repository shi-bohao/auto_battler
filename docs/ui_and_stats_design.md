# UI 与战斗统计设计

> 维护提示：本文档记录主 UI 与统计面板的阶段性设计。后续已新增英雄选择、图鉴、羁绊面板、战斗加速、主菜单素材替换等 UI；当前完整状态请结合 `docs/project_status.md` 和实际场景/控制器查看。

本文档记录当前主界面交互、单位信息展示、出售区域和战斗统计的设计状态。

## 1. 单位头顶信息

单位场景：

- `res://scenes/unit.tscn`

单位逻辑：

- `res://scripts/unit.gd`

当前规则：

- 单位上方只显示单位名称与星级。
- 名称字号已放大，便于战斗中识别。
- 信息显示位置整体向下移动，减少遮挡和离单位过远的问题。
- 生命值使用红色进度条。
- 魔力值使用蓝色进度条。
- 生命条与魔力条都有边框。
- 详细数值不再全部堆在单位头顶，避免战斗画面拥挤。

## 2. 单位详细信息 UI

入口：

- 右键点击单位。

当前展示内容：

- 名称
- 技能：被动技能中文描述、主动技能中文描述
- 基础属性：HP / Max HP
- 护盾
- 攻击力
- 防御
- 攻击间隔
- 攻击范围
- 魔力 / 最大魔力
- 魔力回复
- 暴击率
- 暴击伤害
- 简介
- 设定：职责、稀有度、星级、类型、索敌模式
- 队伍 / 状态 / 阵容位置 / 单位编号
- 移动速度
- 技能伤害倍率 / 治疗倍率
- 当前状态效果
- 运行状态：坐标、格子、当前目标、攻击冷却、重选目标间隔
- 战斗统计快照

设计原则：

- 头顶 UI 只保留快速识别信息。
- 复杂属性进入详情 UI。
- 详情 UI 优先展示技能与基础属性，其次展示简介、设定、状态效果、运行状态和统计。
- 技能展示使用中文效果描述，不再只暴露 `passive_id` / `active_skill_id`。
- 详情 UI 只查看，不修改单位。
- 战斗中查看详情不暂停战斗。

## 3. 遗物显示 UI

主界面：

- `RelicBarPanel` 显示当前已有遗物。
- 主界面只显示一行。
- 默认最多显示 5 个遗物。
- 超出数量显示 `+N`。

详情面板：

- `RelicDetailPanel` 显示全部已拥有遗物。
- 点击遗物后展示名称、稀有度、触发类型、数值和描述。
- 详情面板只用于查看，不允许删除或修改遗物。

## 4. 奖励选择 UI

奖励面板：

- `RewardPanel` 居中显示。
- 战斗胜利后直接弹出奖励面板，不再保留独立奖励按钮。
- 三个奖励按钮固定在面板内。
- 长描述自动换行并裁剪。
- 完整描述保留在 tooltip 中。
- 按稀有度显示底色。
- 指定单位奖励会根据当前阵容显示可升星提醒。

稀有度颜色详见：

- `docs/reward_ui_design.md`

## 5. 出售区域

出售交互从按钮改为拖拽：

- 左下角显示出售区域。
- 准备阶段拖动上场单位或备战席单位到该区域即可出售。
- 出售后返还金币。
- 出售后刷新阵容、战场单位、金币和 UI。

相关代码：

- `scripts/main.gd`
- `scripts/roster_manager.gd`
- `scenes/main.tscn`

主要函数：

| 函数 | 说明 |
| --- | --- |
| `_try_sell_unit_from_drop()` | 处理拖拽出售 |
| `_is_unit_in_sell_zone()` | 判断单位是否落入出售区域 |
| `_set_sell_zone_visible()` | 控制出售区域显示 |
| `sell_active_unit_by_id()` | 出售上场单位 |
| `sell_bench_unit_by_id()` | 出售备战席单位 |

## 6. 战斗统计

统计逻辑：

- `res://scripts/stats_manager.gd`

当前统计字段：

| 字段 | 说明 |
| --- | --- |
| `damage_dealt` | 造成伤害 |
| `damage_taken` | 承受伤害 |
| `kills` | 击杀数 |
| `healing_done` | 治疗量 |
| `shield_given` | 提供护盾量 |
| `mana_restored` | 魔力恢复量 |
| `battle_duration` | 战斗总时长 |

统计展示：

- 战斗总时长。
- 最高伤害。
- 最高承伤。
- 最高击杀。
- 最高治疗。
- 最高护盾。
- 最高魔力恢复。
- 每个单位的伤害、承伤、击杀、治疗、护盾、魔力恢复。
- 遗物伤害总量。

实现原则：

- 死亡单位保留统计快照。
- 治疗量按实际恢复量统计，不统计溢出治疗。
- 护盾量按添加量统计。
- 魔力恢复量按实际恢复值统计，不超过 `max_mana` 的部分。
- 技能、遗物和被动只要走当前统一接口，就尽量纳入统计。

## 7. 验证清单

1. 单位头顶应只显示名称、星级、生命条和魔力条。
2. 右键单位应打开详情 UI。
3. 详情 UI 中应优先看到被动/主动技能描述和基础属性，再看到设定、运行状态和统计快照。
4. 拖动单位到左下角出售区域应出售并返还金币。
5. 战斗结束统计中应显示战斗时间。
6. 牧师、敌方治疗者或回血遗物触发后，应增加治疗统计。
7. 护盾技能或护盾遗物触发后，应增加护盾统计。
8. 魔力回复或魔力遗物触发后，应增加魔力恢复统计。
