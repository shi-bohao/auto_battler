# 商店 UI 与刷新规则

> 维护提示：本文档仍可作为商店结构与刷新规则参考；商店按钮位置、素材样式和相邻 UI 已在后续版本继续调整。当前进度入口见 `docs/project_status.md`。

本文档记录当前商店界面的栏位结构、刷新池、购买状态、升星提醒和遗物详情规则。

## 1. 目标

商店用于准备阶段购买单位和遗物。当前目标是：

- 明确区分已解锁单位、新单位解锁和遗物。
- 让玩家能稳定购买重复单位并推进升星。
- 通过新单位栏位逐步扩展玩家单位池。
- 在单位购买会触发合成时给出可升星提醒。
- 遗物商品可查看完整详情。

## 2. 栏位结构

当前商店共 10 个商品栏位：

| 栏位 | 类型 | 刷新池 |
| --- | --- | --- |
| 1-5 | 已解锁单位 | `RosterManager.get_unlocked_unit_pool()` |
| 6-7 | 新单位解锁 | `RosterManager.get_locked_unit_pool()` |
| 8-10 | 遗物 | `RelicManager.get_available_relic_reward_options()` |

初始已解锁单位为战士、弓手和刺客。通过商店、奖励或随机获得单位时，会同步解锁该单位，使其进入后续已解锁单位刷新池。

## 3. 显示文本

单位商品显示：

```text
单位名  可选：可升至N星
分类 - 稀有度 - 价格
单位简介 / 被动技能 / 主动技能
```

遗物商品显示：

```text
遗物名
遗物 - 稀有度 - 价格
遗物描述
```

空栏位显示占位说明，例如新单位已全部解锁或暂无可购买遗物。

## 4. 交互状态

| 状态 | 按钮文本 | 说明 |
| --- | --- | --- |
| 可购买普通单位 | `购买` | 添加单位到阵容 |
| 可触发升星 | `升星` | 购买后会合成 2 星或 3 星 |
| 新单位解锁 | `解锁` | 购买后解锁并获得该单位 |
| 已售出 | `已售` | 当前刷新周期内不可再次购买 |
| 阵容已满 | `已满` | 单位数量达到上限 |
| 已拥有遗物 | `已拥有` | 遗物不会重复购买 |
| 空栏位 | `-` | 无可用商品 |

可升星单位会在商品名中显示 `【可升至2星】` 或 `【可升至3星】`，并使用更醒目的边框。

## 5. 遗物详情

- 遗物商品卡片可点击。
- 点击后打开 `RelicDetailPanel`。
- 详情显示名称、稀有度、触发类型、数值和描述。
- 已拥有遗物禁购，商店刷新时也会尽量避免重复显示同一轮遗物。

## 7. 性能实现说明

- 购买单位、出售单位、上下阵和合成后仍由 `main.gd` 调用 `_refresh_player_preview_from_roster()` 刷新棋盘预览。
- `BattleManager.refresh_player_and_bench_units()` 不再直接释放所有预览单位并重新生成，而是按 `roster_id` 查找可复用节点。
- 复用节点会记录 `prepare_unit_signature`。当单位资源、星级、阵营、显示名和当前遗物签名没有变化时，只更新位置、拖拽状态、可选中状态和身体样式，跳过 `UnitDataApplier`、美术重载、属性重置和常驻光环重套。
- 当单位发生合成、出售、上下阵、新增或遗物状态变化时，相关节点会走完整重配置，未被复用的旧节点才会释放。
- 遗物购买不会像单位购买一样刷新整队棋盘预览；获得常驻或动态光环遗物后，只刷新对应光环和遗物 UI。

## 8. 验证清单

1. 初始商店前 5 格只刷新战士、弓手和刺客。
2. 第 6-7 格刷新未解锁单位，购买后该单位进入已解锁刷新池。
3. 第 8-10 格刷新遗物，并避免同一轮重复遗物。
4. 购买第三个同名 1 星单位时，商品名和按钮应显示升星提醒。
5. 遗物商品点击后应打开详情面板。
6. 所有 10 个商品栏位和刷新按钮应在商店边框内。
7. 后期阵容较大时，连续购买普通单位不应出现随阵容规模明显增长的整队重建卡顿。
